# Hamza Shiraz — Portfolio

Personal portfolio and brand site for Hamza Shiraz, Creative Designer, Product Designer & Animator.

## Live Site

Open `index.html` in any browser — no build tools or dependencies required.

## Stack

- Pure HTML, CSS, and JavaScript (single file)
- [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) + [Inter](https://fonts.google.com/specimen/Inter) via Google Fonts

## Features

- Animated intro screen with text scramble effect
- Clip-reveal hero title animation
- Gradient mesh blobs with parallax drift
- Marquee skills ticker
- Scroll-triggered fade-in sections
- Animated stat counters
- Active nav indicator tracking scroll position
- Scroll progress bar
- Custom cursor with smooth ring follower
- SVG noise/grain texture overlay
- Fully responsive — two breakpoints (768px, 480px), center-aligned layout

## Sections

1. About — background and skill cards
2. Experience — roles at OBS and freelance
3. Guided Visuals — ongoing visual practice (Instagram + YouTube)
4. Contact — links and email CTA
